# fairino-python-sdk 

Introduction
---------------
This is a Python language SDK library specially designed for fairino collaborative robots.

Installation
---------------
Add the line
~~~
fairino @ git+https://github.com/cbrahana-insyte/fairino-python-sdk.git#subdirectory=linux
~~~
to your pyproject.toml in the dependencies = [...] section.

Documentation
----------------
Please see [Python SDK](https://fair-documentation.readthedocs.io/en/latest/SDKManual/python_intro.html)。
